# Todo List App

Todo List - веб-приложение для управления задачами с возможностью добавления, редактирования, удаления и сортировки.
cостояние списка сохраняется в localStorage, интерфейс реализован через методы DOM без использования innerHTML, чистый js, адаптивная верстка под десктопы, планшеты и телефоны

https://todolistpixelapp.vercel.app/
